# Legacy attendance records

- `GET /attendance/legacy-records` replaces legacy-data GET. Requires `attendance:edit`, strict cursor/limit (50 default, 100 maximum), optional search (200 characters) and strict isMapped boolean. IDs ascend; lookahead determines nextCursor. UTC ISO dates, nullable mappedUser limited to id/username/avatarUrl; no email. Other mapped users and unmapped legacy identities are read-audited; self-only and empty pages are not. Lookahead identities are excluded. Audit failures return 500 without data.
- `PATCH /attendance/legacy-records/{id}` replaces legacy-data PUT. Requires superadmin, strict `{mappedUserId: positiveInt32|null}`, missing references 404. Serializable mapping update and `legacy_attendance.mapping_updated` audit commit together; before/after include mapping IDs/flags only, targets include old/new users. Returns the same record DTO.
- `POST /attendance/legacy-records/import` replaces attendance/legacy-import. Requires attendance:edit; strict `{csvData:string,previewOnly?:boolean}`; maximum 1MB CSV and 5000 valid cells. Explicit `YEAR: YYYY` required; RANK/NAME headers and day-Mon date columns; ID optional. Quoted CSV commas/escaped quotes/CRLF supported. Dates are UTC midnight; one chronological December→January rollover assigns earlier columns to the previous year. Reject invalid calendar dates, duplicate date columns and ambiguous multiple rollovers.
- Preserves P/A/NA import and skips LOA/NO/EO/empty cells. Unknown status values fail validation. No valid cells returns 422. Dedup identity uses legacyUserId when present, otherwise legacyName, plus UTC date, fixing unrelated missing-ID records being merged. Duplicates within the uploaded CSV are also detected. Conflicting status sets prevent all writes with 409; preview reports conflicts. Duplicate-only imports return success with imported=0. No hidden conflict resolution input is accepted.
- Both preview/import return `{imported,year,dateColumns,skippedCells,processedCells,duplicates:{same,different},conflicts,preview}` under data/meta. Preview returns candidate rows and audits existing-person data consulted for its response; no records are inserted. Commit returns an empty preview list. Serializable transaction inserts all cells and one `legacy_attendance.imported` audit containing created record IDs/counts, not names or CSV text. No outbox event is emitted. P2002/P2003/P2034 return409.
- UI reads every cursor page, uses canonical mapping/import calls and displays API errors. Removed nonfunctional conflict-choice buttons (the old API never received those choices); users correct the CSV then preview again. Mapping selection/groups distinguish attendance and legacy-user records even when numeric IDs/names collide. Legacy-user import endpoints remain for their next batch.

Validation: 27 unit tests and six Prisma integration tests, including UTC rollover, missing-ID dedup, live credentials/permissions, strict inputs, mapping scope/read privacy and real rollback after failed audits.
